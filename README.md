# Audius (audius)

Audius is a decentralized open-source music streaming platform built on the Open Audio Protocol. It exposes a public REST API for tracks, users, playlists, search, and resolve, plus a JavaScript SDK. The protocol layer is open-source on GitHub.

## APIs

### Audius REST API
Public REST API for the Audius network. Endpoints cover tracks (metadata, stream, trending), users (profile, followers), playlists, search, and resolve (lookup by URL). API hosts are discovered dynamically from the network; many host paths are accessible at /v1.
- **Base URL:** `https://api.audius.co`
- **Docs:** https://docs.audius.org/developers/api
